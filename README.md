# team-tasks（チーム共有タスク管理）

チームでタスクを共有・管理するための、シンプルなタスク管理アプリです。

## 主な機能

- タスク追加（タイトル / 締切日 / 優先度[高・中・低] / 担当者）
- 完了チェック（トグル）
- タスク削除
- フィルタ: すべて / 未完了のみ / 完了のみ
- ソート: 締切順 / 優先度順
- 期限切れバッジ（未完了かつ締切日が今日より前のタスクに表示）

## 動作環境

- Node.js 18 以上

## セットアップ

```bash
npm install
npm start
```

`npm start` で開発サーバーが起動します。表示された URL（例: http://localhost:5173）をブラウザで開いてください。

初回起動時は localStorage が空のため、サンプルタスク（seed データ）が自動的に投入されます。

## その他のコマンド

```bash
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果のプレビュー
npm run typecheck  # 型チェックのみ（tsc --noEmit）
```
